# 多语言 → 简体中文与 85% 背景

验证日期：2026-10-24。当前模型保持 Qwen3-ASR-1.7B Q8_0 + HY-MT2-7B Q4_K_M；speech.cpp、llama.cpp 版本和权重来源保持 [模型升级记录](QWEN_HY_UPGRADE.md)。本次没有更换模型、修改驱动或全局音频设备。

## 使用与行为

```bash
livetranslate-start
# 直接以日语模式启动
livetranslate-start --language ja
```

窗口顶部提供英语、日语、韩语、法语、德语、西班牙语、意大利语、俄语 → 中文。纯字幕模式通过右键“返回双框与设置”打开语言选择器。默认英语；选择立即影响后续音频，无需重新加载模型。切换清空上下框、字幕历史与翻译上下文，丢弃旧语言排队及在途结果，建议在停顿处切换，避免截断当前句。单次窗口选择不写入配置；持久设置需在本机 TOML 的已有 `[asr]` 表修改 `language = "ja"`。CLI `live`、`demo`、`transcribe`、`translate` 都接受 `--language en|ja|ko|fr|de|es|it|ru`。

默认浅色主题、16 号黑字、**85% 背景不透明度**。滑块仍只影响单层背景，文字和边框保持不透明。显式 TOML `stream.opacity` 仍优先，透明主题仍无填充。当前本机配置没有旧 opacity 覆盖。

Whisper Small.en 是英语专用回退，不支持另外七种语言；GUI 禁用这些选项，非英语配置直接报错。已有多语言 Whisper 模型可通过配置指定，但本次没有下载或实测多语言 Whisper。

例如 `livetranslate-start --language ko`。模型和 Vulkan 引擎版本保持不变。语言注册表统一控制 GUI、CLI、配置校验和翻译提示；英文提示保持此前版本，新增语种明确提示其源语言。韩语按空格词组计算稳定前缀，较短稳定片段即可触发临时翻译；其他新增语种兼容重音字符、西里尔字母、倒问号及句末引号，不再沿用英语功能词裁剪。切换仍按语言代次隔离队列、缓存和字幕上下文。

**344 项测试全部通过**，包含原有 3 项真实模型回归。新增验证六个选项的 UI 绑定、八种 CLI/TOML 参数、每种新语言的 CLI 与 HTTP ASR 参数、翻译提示中的实际语言名称、Unicode 稳定前缀、句读处理、上下文隔离、英语专用 Whisper 拒绝以及 700 px 窗口内控件布局。JUnit：`artifacts/languages-six-20261024/pytest-final.xml`。

每种语言使用 Google [FLEURS](https://huggingface.co/datasets/google/fleurs) 固定 revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd` 的 `test` 第一条归档真人 WAV：`ko_kr`、`fr_fr`、`de_de`、`es_419`、`it_it`、`ru_ru`，许可证 CC BY 4.0。各用 HTTP 206 Range 读取归档前 8 MiB，只提取第一段，不下载完整语料。参考 TSV 仅用于结果检查，未传给模型。文件名、参考文本、来源和 SHA-256 在 `artifacts/languages-six-20261024/provenance.json`。

法语原始录音 RMS 为 -62.12 dBFS，首次文件管线按既有 -60 dBFS 门限拒绝，失败记录保存在 `fr/pipeline.json`。没有修改静音门限。测试为六段原始录音分别生成增益归一化副本：目标 -18 dBFS，同时限制线性峰值不超过 0.85；达到峰值上限的片段不再增加增益，因此可能低于目标 RMS。法语增益 +44.12 dB，从原始高精度 WAV 放大后转换 PCM16，避免先量化再放大的损失。原始文件保留，参数在 `normalization.json`。没有合成语音或替换识别答案。
