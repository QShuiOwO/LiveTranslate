# 英语／日语 → 简体中文与 85% 背景

验证日期：2026-10-24。当前模型保持 Qwen3-ASR-1.7B Q8_0 + HY-MT2-7B Q4_K_M；speech.cpp、llama.cpp 版本和权重来源保持 [模型升级记录](QWEN_HY_UPGRADE.md)。本次没有更换模型、修改驱动或全局音频设备。

## 使用与行为

```bash
livetranslate-start
# 直接以日语模式启动
livetranslate-start --language ja
```

窗口顶部新增“英语 → 中文 / 日语 → 中文”。默认英语；选择立即影响后续音频，无需重新加载模型。切换清空上下框、字幕历史与翻译上下文，丢弃旧语言排队及在途结果，建议在停顿处切换，避免截断当前句。单次窗口选择不写入配置；持久设置需在本机 TOML 的已有 `[asr]` 表修改 `language = "ja"`。CLI `live`、`demo`、`transcribe`、`translate` 都接受 `--language en|ja`。

默认浅色主题、16 号黑字、**85% 背景不透明度**。滑块仍只影响单层背景，文字和边框保持不透明。显式 TOML `stream.opacity` 仍优先，透明主题仍无填充。当前本机配置没有旧 opacity 覆盖。

Whisper Small.en 是英语专用回退，不支持日语；GUI 禁用该选项，日语配置直接报错。已有多语言 Whisper 模型可通过配置指定，但本次没有下载或实测多语言 Whisper。

## 同一窗口切换的真实 HDMI 短测

证据目录：`artifacts/languages-20261024/live-switch/`；执行器为上级目录的 `validate-switch.py`。真人英语 JFK → 日语第二、第三片段 → JFK，使用 `paplay --device` 定向播放到已有 HDMI sink，从对应 monitor 连续捕获，没有改变系统默认输出。Qt 主线程直接选择真实窗口的下拉框，切换两次；Qwen 和 HY 服务各只启动一次，无重载。

- 会话 59.83 秒，实际连续 PCM 57.78 秒；四次播放均自然结束。
- 10 条最终原文和 10 条最终双语（英语 8、日语 2），全部有有效可见窗口绘制。
- 日语有 20 个临时字幕更新事件，其中 10 个带临时译文；英语／日语均在音频结束前产生更新。
- 0 推理错误、过期任务、音频／推理队列丢弃、采集缺口／重连、最终字幕改写；结束后无存活工作线程。

日志与 GPU 枚举共同确认 Qwen3-ASR 加载到 **RX 9070 XT / Vulkan0**；llama 日志记录 Vulkan0 模型缓冲 4403.24 MiB、33/33 层卸载。5 秒资源采样共 12 次：主进程 RSS 峰值 145.37 MiB、拥有的进程树 RSS 峰值 1048.74 MiB、进程树 CPU 峰值 13.39%（单核=100%）、整卡显存观测峰值 8.64 GiB、GPU 利用率观测峰值 99%。整卡数据包含桌面及其他进程，低频采样可能漏峰值；不能解释为模型独占用量。

按本阶段要求仅做短测，未重跑 30 分钟长测或系统性日语准确率评测；旧 M2 英语长测结果保留在原报告中。
