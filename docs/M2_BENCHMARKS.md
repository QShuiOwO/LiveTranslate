## 时间戳

全部使用同机 monotonic_ns，不混用系统 UTC 与模型生成 token 时间：

| 时间戳 | 定义 |
| --- | --- |
| PCM frame start/end | FFmpeg monitor pipe 读入时刻；同一读批内每帧 20 ms 回推 |
| speech onset | 当前段第一帧满足 VAD 和能量门限的 frame start |
| speech end | 当前段最后满足 VAD 和能量门限的 frame end |
| queued | ASR 或翻译任务入有限队列时刻 |
| first English / Chinese paint | 当前 ID 对应语言第一次完成 QLabel 绘制，窗口须 visible 且 exposed |
| final bilingual paint | 英文 final 与中文 final 绘制的较晚时刻 |

- 英文首条时延 = first English paint − speech onset。
- 中文首条时延 = first Chinese paint − speech onset，可能是明确标为临时的译文。
- 最终双语从起点时延 = final bilingual paint − speech onset，包含说话本身长度。
- 最终双语从终点时延 = final bilingual paint − speech end，包含停顿等待、排队、推理和绘制。

QLabel 的完成时刻表示 Qt 完成这次文字绘制，不是物理面板发光时刻。截图 grab 会触发额外绘制，已用标记排除；headless 不记录显示时延。未测量最初 Pulse/HDMI 设备缓冲、VAD 边界误差、合成器提交到屏幕扫描的延迟。播放投递时刻单独记录为参照，不冒充实际扬声器起音。

Qt visible/exposed 的具体含义由显示平台决定，不是逐像素遮挡检测。xcb 测试另核对窗口 _NET_WM_STATE_ABOVE，并在真实桌面保持窗口可见；绘制覆盖率表示符合上述条件的 QLabel 事件覆盖，不是外部摄像或光电探头测得的屏幕覆盖率。

P50/P95 采用样本排序后线性插值，列出 n。窗口遮挡/最小化时不生成假的绘制事件；该部分应单独披露样本覆盖率，不能与模型回复时间混用。模型调用耗时、队列等待和上述语音到显示指标分别报告。

## 资源与稳定性

每 5 秒采样进程树 CPU、应用 RSS、拥有的子进程 RSS、RX 9070 XT 全设备 GPU busy/VRAM 和队列深度。CPU 的 100%=一个逻辑核；整卡显存包含桌面及其他进程。5 秒采样可能漏掉很短的 GPU 峰值，设备与权重 offload 证据另取原生启动日志。

30 分钟内存观察预先使用 10–15 分钟窗口均值与最后 5 分钟均值比较，并计算 10 分钟后的 OLS 斜率。辅助门限：应用增长 <64 MiB、拥有的进程树增长 <128 MiB、应用斜率 <1 MiB/分钟。通过仅表示本次运行没有观察到明显泄漏，不证明无限时长无泄漏。初期模型、Qt 字形与字幕历史增长不与稳态混为一谈。

有界性另检查队列 high_water、丢弃/过期、字幕行上限、ID 唯一及最终英文改写记录。相同词句在源音频中重复不属于字幕重复；同一 ID 被重复插入历史或已确认英文发生变化才属于状态错误。

原始分析命令：`python scripts/analyze_stream.py artifacts/my-soak`。完整绘制覆盖率 98% 是额外观察项；桌面遮挡导致未达到时需报告为未达到，不能隐藏或补时间戳。
