# 有限英文上下文翻译

日期：2026-10-24。针对口语中 “What if I do like this?” 被理解为“喜欢”的问题，实时翻译现在默认参考最多两段已确认英文。上下文仅帮助理解当前段，输出仍只包含当前段的简体中文。

## 行为与边界

- ASR 工作线程保存英文 final，当前段在取出上文快照后才进入历史。临时识别、当前段自身、后续段和旧中文译文不会作为上文。
- 最多两段、总计 800 字符（含分隔换行），有效期 30 秒。超字符预算时丢弃最旧整段；单段自身过长时跳过，不截成可能改变意思的片段。因此可保留更早但仍在有效期内的短段。
- 年龄为当前段 `onset_ns` 减前文 `speech_end_ns` 的音频时间，非 HTTP 请求墙钟时间。相邻读批次引起的微小负间隔按 0 处理。
- 每个 TextJob 保存不可变的上下文 tuple，异步翻译排队不会读到后面新加入的句子。此前英文即使翻译失败，仍可成为下一段的参考。
- AudioFrame 的采集 epoch 传到 SpeechJob；Segmenter 另维护 continuity，在 epoch 或帧序号断点变化时递增。即使切换发生在静音、没有旧语音段可提交，也会给下一段标记新边界。
- 首个新边界任务清空旧英文历史。翻译缓存包含 epoch、continuity、上下文及当前文本，边界变化时清空；同一句在不同语境不会复用旧译文。停止后的新会话创建全新历史。
- 历史仅保存在 ASR 工作线程中，任务快照和原有有界队列、128 条翻译缓存一起受限。没有无限对话缓存，也不将旧中文反复提供给模型。

HY-MT2 使用已实测的背景/当前文本提示格式；无上下文时保留原提示。Whisper + Qwen 回退配置的翻译客户端同样支持此参数。文件 demo 和单次 translate 没有跨段历史，默认仍独立翻译；Python 客户端支持 `translate(text, context=(...))`。

## 配置

在现有 TOML 的 `[translation]` 表内设置：

```toml
context_segments = 2
context_max_chars = 800
context_max_age_s = 30.0
```

`context_segments = 0` 可关闭上下文。段数允许 0–4，字符预算 128–2000，有效期 1–120 秒；非法配置报错。客户端拒绝非字符串、空白上下文、超段数/字符预算，不发送无效请求。原始识别文本不做固定词语替换。

`translation_request` 事件记录上下文段数、字符数、采集边界和缓存命中；单次翻译 metrics 也记录上下文规模，不重复保存整段上下文文字。

## 真实回归

使用当前本地 Hy-MT2-7B Q4_K_M / llama.cpp / RX 9070 XT Vulkan，temperature=0、seed=42、max_tokens=256。直接读取原会话已保存的 ASR 文本，经生产 TranslationContext 和 LlamaTranslator 测试。

| 检查 | 实际结果 |
|---|---|
| 原完整段，无前文 | 复现“如果我确实喜欢这个的话怎么办？” |
| 原完整段，带前两段实际英文 | 连续 3 次均为“要是我这么做会怎样？” |
| “I really do like this painting.” | “我真的很喜欢这幅画。” |
| 明确要求照某种方式操作 | “请按这种方式来，不要改变形状。” |
| 同一歧义短句，前文讨论是否喜欢画作 | “要是我真的喜欢上这幅画怎么办？” |

有上下文的三次完整段请求耗时 476.88 / 471.94 / 470.96 ms，中位 471.94 ms。该数字包含本地健康/模型检查、HTTP 及生成，不是字幕显示延迟，也不据此声称比无上下文更快。共 7 次真实模型调用，原文和完整结果仅在忽略目录 `artifacts/translation-context-20261024/real-context-regression.json`。

另以同样真实上文检查较短的临时前缀 “All right. What if I do like this?” 和裸短句，两者也译出“这么做”的含义，见 `real-partial-check.json`。

原会话未保存录音，因此不能判断 ASR 当时是否漏掉 `it`；本回归验证翻译消歧，不冒充原场景的重新语音识别。

## 管线与测试

- 完整 pytest：**218 passed**，包括原有 3 项真实模型测试。覆盖上文段数/字符/时间、临时与 final 分离、异步快照、缓存隔离、静音期换源/丢帧、翻译失败、关闭上下文及无上下文兼容。
- 另通过 35.48 秒真实 HDMI / Qt xcb 字幕短测：33.34 秒 PCM，4/4 双语字幕完成有效绘制；0 错误、丢帧、任务丢弃、过期、重连或最终字幕改写，退出无存活 worker。
- 真实请求的上下文段数依次为 **0、1、2、2**，证明连续管线实际启用了有限历史。
- 语音首帧至英文首绘 P50/P95：1121.95 / 1204.76 ms；至中文首绘：2803.89 / 3576.99 ms；最后有声帧至最终双语：836.67 / 859.80 ms。仅 4 条样本，沿用 PCM 入应用到可见 QLabel 绘制口径，未测物理屏幕延迟。

证据：`artifacts/translation-context-20261024/pytest-final.xml` 和 `live-short/`。字幕素材为官方 JFK 人声，经 HDMI 播放并捕获 monitor，使用真实 Qwen3-ASR 与 HY-MT2；没有使用人工转录替代这项系统音频测试。

本次只做短测，未重跑 30 分钟验收。上下文能改善此例，仍不能保证所有省略、误识别或依赖视频画面的口语都无歧义。
